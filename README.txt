PLANIFICADOR SEMANAL V5 — PWA PARA CHROME ANDROID

Subir TODOS estos archivos al repositorio de GitHub Pages:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

Luego activar GitHub Pages desde Settings > Pages, usando la rama principal y / (root).
Abrir la URL HTTPS en Chrome Android y elegir Instalar aplicación / Agregar a pantalla de inicio.

Firebase permanece dentro de index.html. La instalación PWA requiere HTTPS (GitHub Pages).
